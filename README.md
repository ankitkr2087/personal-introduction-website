
# Personal Introduction Website

[🌐 View Live Website](https://ankitkr2087.github.io/personal-introduction-website/)

A personal portfolio-style webpage built with HTML, CSS, and JavaScript.

## ✨ Features

- Dark and light theme toggle with saved theme preference
- Animated typing effect for the introduction
- Animated skill bars
- Responsive layout for mobile and desktop screens
- Personal interests and social links

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Explore the page and switch between light and dark themes.

## 📚 What I Learned

- Structuring a webpage with HTML
- Styling layouts with CSS and media queries
- Adding interactivity with JavaScript
- Using browser local storage to remember preferences
- Creating animations and interactive UI elements

## 🎯 Purpose

This project was developed while practising frontend development, originally in the context of a college coding-club recruitment task.
